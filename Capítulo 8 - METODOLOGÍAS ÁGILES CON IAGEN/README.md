# Capítulo 8: Metodologías Ágiles con IAGen

Esta carpeta contiene las fuentes bibliográficas, documentos de apoyo y resúmenes correspondientes al **Capítulo 8: Metodologías Ágiles con IAGen** del libro de ISFW basado en IAGen.

## Contenido

* **Fuentes/**: Contiene los libros, artículos científicos, informes técnicos y demás documentos utilizados como base para la investigación del capítulo, tanto en `pdf/` como en `markdown/`.
* **Resúmenes/**: Contiene los resúmenes solicitados.

## Subtemas del capítulo

* 8.1 Fundamentos ágiles aplicados al caso faro: valores, principios y trabajo incremental.
* 8.2 Scrum aplicado: roles, eventos, backlog, sprint y revisión del incremento.
* 8.3 Kanban aplicado: flujo de trabajo, límites WIP, seguimiento y mejora continua.
* 8.4 Retrospectivas, coevaluación y mejora del proceso con apoyo de IAGen.
* 8.5 Resumen, preguntas de reflexión, presentación final y memoria de aprendizaje del caso faro.

## Metodología de trabajo

1. Seleccionar y recopilar fuentes académicas actualizadas (2021–2026).
2. Convertir las fuentes relevantes a formato Markdown (`.md`) para optimizar su uso en NotebookLM.
3. Elaborar un resumen de cada subtema utilizando las fuentes seleccionadas.
4. Incorporar citas y referencias bibliográficas siguiendo la normativa IEEE.
5. Generar, cuando sea necesario, recursos gráficos y tablas para complementar el contenido del capítulo.
